\# ✍️ Handwritten Digit Recognizer



A simple and interactive \*\*Handwritten Digit Recognition\*\* application built with Python and Machine Learning.



The application allows users to draw a digit from \*\*0 to 9\*\* and predicts which digit was drawn.



\## ✨ Features



\- 🖊️ Draw a handwritten digit using your mouse

\- 🤖 Predict digits from \*\*0–9\*\*

\- 🎯 Interactive graphical user interface

\- 🧹 Clear the drawing with one click

\- ⚡ Fast prediction

\- 🐍 Built with Python



\## 🛠️ Technologies Used



\- Python

\- Machine Learning

\- Tkinter

\- NumPy

\- OpenCV

\- PIL / Pillow
